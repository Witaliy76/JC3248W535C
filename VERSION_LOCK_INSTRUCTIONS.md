# ИНСТРУКЦИИ ПО ЗАФИКСИРОВАННЫМ ВЕРСИЯМ

## ЗАЧЕМ ЭТО НУЖНО?
Проект использует специфические версии компонентов, которые были протестированы и работают стабильно. 
Изменение версий может привести к ошибкам компиляции.

## ЗАФИКСИРОВАННЫЕ ВЕРСИИ:

### PlatformIO Platform
- **espressif32@6.4.0** - стабильная версия PlatformIO для ESP32
- **НЕ МЕНЯТЬ** без тестирования

### ESP32 Arduino Core
- **framework-arduinoespressif32@2.0.17** - поддерживает ADC_ATTEN_DB_12
- **НЕ МЕНЯТЬ** на 2.0.14 (нет ADC_ATTEN_DB_12) или 3.x (несовместимо с Arduino_GFX)

### Arduino_GFX Library
- **Локальная версия 1.6.0** в папке `src/src/GFX_Library_for_Arduino/`
- **НЕ СКАЧИВАТЬ** с GitHub - там версия для ESP32 Core 3.x

## ЧТО НЕ:

❌ **НЕ раскомментируйте** строки в `platformio.ini`:
```ini
; lib_deps = 
;     https://github.com/moononournation/Arduino_GFX.git
```

❌ **НЕ обновляйте** ESP32 Arduino Core до версии 3.x

❌ **НЕ скачивайте** Arduino_GFX с GitHub

## ЧТО ДЕЛАТЬ ПРИ ПРОБЛЕМАХ:

1. **Очистите кэш PlatformIO:**
   ```bash
   pio run --target clean
   ```

2. **Переустановите зависимости:**
   ```bash
   pio lib install
   ```

3. **Проверьте версии:**
   ```bash
   pio platform show espressif32
   ```

## ПРОВЕРКА ВЕРСИЙ:

После компиляции в логе загрузки должно быть:
```
##[BOOT]#       esp32core:      2.0.17
```

## КОНТАКТ:
При возникновении проблем с компиляцией - проверьте соответствие версий этим инструкциям.
